## Descripción del Repositorio
Repositorio dedicado al dominio y la práctica de la **Programación Orientada a Objetos (POO)** en Python. Los programas de esta unidad abarcan la implementación de clases, constructores, herencia, polimorfismo y composición. 

Cada script incluye un estilo de documentación detallada con comentarios línea por línea para justificar y explicar cada instrucción.

---

## Características Principales
* **Fundamentos de POO:** Uso correcto de `class`, constructores (`__init__`), referencias a objetos (`self`) y métodos especializados.
* **Herencia y Polimorfismo:** Reutilización eficiente de código mediante clases base/derivadas y el uso de `super()`.
* **Composición:** Modelado de relaciones complejas e intercambio de flujos avanzados entre objetos.
* **Documentación Explicativa:** Comentarios detallados en la totalidad del código para facilitar el estudio y la revisión.
